# ASCIIBOI

A small creature who used to be a file and now has a URL.

## Live

Public habitat: [https://srandee.github.io/asciiboi/](https://srandee.github.io/asciiboi/)

If that link 404s, GitHub Pages still needs one switch in the repo:

1. Open [Settings → Pages](https://github.com/Srandee/asciiboi/settings/pages)
2. Under **Build and deployment**, set **Source** to **GitHub Actions**
3. Re-run the **Deploy to GitHub Pages** workflow if it did not already finish

## Local

Open `docs/index.html` or serve the folder:

```bash
python3 -m http.server 4173 --directory docs
```

Then visit `http://localhost:4173`.
